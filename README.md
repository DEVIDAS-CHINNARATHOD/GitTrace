# GitTrace

GitTrace is a simple Cyberpunk-themed GitHub user tracker.  
It shows a list of GitHub users, and clicking on a user opens a profile modal with basic details.

## Features

- Cyberpunk neon-themed UI
- Mobile-friendly layout
- Click on a user card to view:
  - Avatar
  - GitHub username
  - Bio/description
  - Followers & Following
  - Public repositories
  - Link to GitHub profile
- Read-only view (no add/remove)
- Fully frontend-only (no backend needed)

## File Structure

GitTrace/
├─ index.html
├─ style.css
├─ script.js
├─ gitusers.json
└─ README.md


## How to Use

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Click on any user card to see their GitHub profile details.
4. To update the user list, edit `gitusers.json` and refresh the page.

## Tech Stack

- HTML5
- CSS3 (Cyberpunk theme)
- JavaScript (Fetch API)
- GitHub REST API
